# ⚙️ PugJS Boilerplate

A modern frontend boilerplate built with **Pug.js**, **Sass**, **Babel**, and **Gulp.js**. Designed to streamline your development workflow and make static site creation fast, modular, and scalable.

---

## 🚀 Features

- ⚡ **Pug.js** – Simple and powerful HTML templating
- 🎨 **Sass** – Modular and clean CSS with variables, mixins, and nesting
- 🧠 **Babel** – Use modern JavaScript (ES6+) with backward compatibility
- 🛠️ **Gulp.js** – Task runner for efficient development and production builds
- 🗂️ Organized file structure for scalable projects
- 🔄 Live reload and auto-watch for a smooth dev experience
- 📦 Optimized assets for production

## 📦 Getting Started

1. **Install dependencies**  
```
npm install
```

2. **Run development server**  
```
gulp
```

3. **Build for production**
```
gulp build
```

---

## 📌 Requirements

- Node.js >= 14  
- npm or yarn  
- Gulp CLI installed globally
